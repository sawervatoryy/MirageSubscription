# MirageSubscription

Премиум подписка для Paper 1.21.4+ за **донат-валюту (PlayerPoints)** или **рубли**.
Анимированное меню, настраиваемые бонусы, плейсхолдеры для TAB / scoreboard.

## Возможности

- **Два способа оплаты** на выбор игрока: поинты (PlayerPoints) или рубли.
- **Меню `/premium`** с анимацией открытия (предметы расходятся кольцами от центра), бегущей волной по рамке и пульсацией иконки статуса.
- **GUI можно отключить** (`gui.enabled: false`), при этом все команды продолжают работать.
- **Несколько тарифов** (по умолчанию неделя / месяц / сезон), цена задаётся отдельно для каждой валюты.
- **Бонусы трёх типов** (`ACTIVATE`, `DAILY`, `PASSIVE`), настраиваются в `bonuses.yml` **или прямо в игре** командами `/msub bonus ...`.
- **Плейсхолдеры PlaceholderAPI** `%miragesub_...%` для TAB, scoreboard и любых других плагинов.
- Автоматическое **окончание подписки**: откат PASSIVE-бонусов, уведомление игрока, предупреждение за N дней до конца при входе.
- Все данные в памяти, запись на диск **асинхронная**, главный поток не блокируется.
- Все сообщения и тексты меню вынесены в `lang.yml`, настройки в `config.yml`, ничего не захардкожено.

## Требования

| Компонент | Версия | Обязательность |
|-----------|--------|----------------|
| Paper | 1.21.4+ | обязательно |
| Java | 21+ | обязательно |
| PlayerPoints | 3.x | нужен для оплаты поинтами (без него работают только рубли) |
| PlaceholderAPI | 2.11+ | нужен для плейсхолдеров |
| TAB | любая актуальная | по желанию, для вывода статуса в таблист/scoreboard |
| LuckPerms (или иной плагин прав) | любая | по желанию, для PASSIVE-бонусов с группами |

Внешних библиотек плагин не использует (секция `libraries` в `plugin.yml` пуста, shade не применяется).

## Установка и сборка

### Сборка

```bash
mvn clean package
```

Готовый jar: `target/MirageSubscription-v0.1.jar`.

Репозитории в `pom.xml`:

- PaperMC: `https://repo.papermc.io/repository/maven-public/`
- PlaceholderAPI: `https://repo.helpch.at/releases/`
- PlayerPoints: `https://repo.rosewooddev.io/repository/public/`

> Работа с PlayerPoints идёт через `look`/`take`/`give` (`PlayerPointsProvider`). Если в вашей версии API они называются иначе, правится один этот класс.

### Установка

1. Положите jar в `plugins/`.
2. Убедитесь, что установлены PlayerPoints и PlaceholderAPI (если нужны).
3. Запустите сервер. Создадутся `config.yml`, `lang.yml`, `bonuses.yml`, позже `data.yml`.
4. Отредактируйте тарифы и бонусы, затем `/msub reload`.

## Быстрый старт

1. В `config.yml` задайте цены тарифов (`plans.*.price.points` / `price.rubles`) и ссылку магазина `currencies.rubles.store-url`.
2. В `bonuses.yml` замените пример `premium-group` на вашу группу прав.
3. Проверьте покупку: выдайте себе рубли `/msub rub add <ник> 500`, откройте `/premium` и купите тариф.
4. Подключите плейсхолдеры в TAB (см. [раздел](#плейсхолдеры-и-tab)).
5. Настройте веб-магазин так, чтобы после оплаты он выполнял из консоли `msub rub add <ник> <сумма>`.

## Команды и права

### Игрок: `/premium` (алиасы `/premuim`, `/prem`)

| Команда | Описание |
|---------|----------|
| `/premium` | Открыть меню (если GUI выключен, покажет статус и помощь) |
| `/premium gui` | Открыть меню явно |
| `/premium status` | Статус подписки: тариф, остаток, дата окончания |
| `/premium plans` | Список тарифов с ценами |
| `/premium buy <тариф> <points\|rub>` | Купить подписку выбранной валютой |
| `/premium bonuses` | Список бонусов и их состояние |
| `/premium claim <бонус>` | Забрать DAILY-бонус |
| `/premium help` | Помощь |

Допустимые написания валюты: `points`, `pp` для поинтов; `rub`, `rubles`, `руб` для рублей.

### Администратор: `/msub` (алиасы `/mirsub`, `/subadmin`)

| Команда | Описание |
|---------|----------|
| `/msub give <игрок> <тариф\|дни>` | Выдать или продлить подписку. Число — это дни, тарифы берутся из `config.yml` |
| `/msub take <игрок> <дни>` | Уменьшить срок (если срок кончился, подписка завершается) |
| `/msub revoke <игрок>` | Немедленно отменить подписку |
| `/msub check <игрок>` | Тариф, остаток, дата окончания, рублёвый баланс |
| `/msub rub add <игрок> <сумма>` | Пополнить рублёвый баланс |
| `/msub rub take <игрок> <сумма>` | Списать рубли |
| `/msub rub set <игрок> <сумма>` | Установить баланс |
| `/msub rub balance <игрок>` | Показать баланс |
| `/msub reload` | Перечитать `config.yml`, `lang.yml`, `bonuses.yml` |

Команды `/msub` можно вызывать из консоли. Игрок должен хотя бы раз заходить на сервер: плагин ищет его по кэшу имён и не делает сетевых запросов.

#### Редактор бонусов `/msub bonus`

| Команда | Описание |
|---------|----------|
| `list` | Список бонусов |
| `info <id>` | Параметры и команды бонуса |
| `create <id> [тип]` | Создать бонус (тип по умолчанию `DAILY`) |
| `delete <id>` | Удалить бонус |
| `setname <id> <название>` | Название (поддерживает `&` и `&#RRGGBB`) |
| `seticon <id> [предмет]` | Иконка; без аргумента берётся предмет из руки |
| `settype <id> <ACTIVATE\|DAILY\|PASSIVE>` | Тип |
| `setcooldown <id> <часы>` | Кулдаун для DAILY (можно дробные, например `0.5`) |
| `addlore <id> <текст>` | Добавить строку описания |
| `clearlore <id>` | Очистить описание |
| `addcmd <id> <команда>` | Добавить консольную команду |
| `delcmd <id> <номер>` | Удалить команду по номеру (см. `info`) |
| `addrevert <id> <команда>` | Добавить команду отката (для PASSIVE) |
| `delrevert <id> <номер>` | Удалить команду отката |

`id` бонуса: латиница, цифры, `_` и `-`, до 32 символов. Изменения сразу применяются и асинхронно сохраняются в `bonuses.yml`.

### Права

| Право | По умолчанию | Описание |
|-------|--------------|----------|
| `miragesubscription.use` | все | Использовать `/premium` |
| `miragesubscription.admin` | OP | Использовать `/msub` |

## Конфигурация (config.yml)

```yaml
settings:
  expiry-check-seconds: 30     # как часто проверять окончание подписок
  notify-before-days: 3        # предупреждать при входе за N дней до конца (0 — выкл.)
  save-interval-seconds: 60    # период автосохранения data.yml
  date-format: "dd.MM.yyyy HH:mm"

gui:
  enabled: true                # false — меню отключено, команды работают
  animation:
    enabled: true              # анимация открытия
    open-step-ticks: 2         # скорость раскрытия меню
    idle-step-ticks: 4         # скорость волны по рамке (0 — выкл.)
    palette: [...]             # цвета рамки, по ним бежит волна
  sounds:                      # ключи звуков Minecraft
    enabled: true
    open / step / click / success / error
  icons:                       # материалы иконок меню
    status-active, status-inactive, bonuses, close, back, points, rubles, unavailable

currencies:
  points:  { enabled: true, name: "поинтов" }
  rubles:  { enabled: true, name: "руб.", symbol: "₽", store-url: "https://..." }

plans: { ... }                 # см. раздел «Тарифы»

placeholders:
  active:   "&#00ACFFPremium"  # %miragesub_status% при активной подписке
  inactive: "&7Нет"            # %miragesub_status% без подписки
  none:     "&7-"              # значение «пусто» для timeleft / expires / plan
```

Заметки:

- Если в файле не хватает ключей (например, после обновления плагина), недостающие значения берутся из версии внутри jar.
- Неверное имя материала или слот вне диапазона 0–53 не ломает плагин: пишется предупреждение в консоль и используется значение по умолчанию.
- Анимацию можно выключить полностью (`gui.animation.enabled: false`) для слабых клиентов или серверов.
- `/msub reload` перезапускает фоновые задачи с новыми интервалами.

## Валюты и рубли

### Донат-валюта (PlayerPoints)

Списание идёт через API PlayerPoints (`look`/`take`/`give`), вызовы выполняются в виртуальных потоках, а не на главном потоке. Если плагин не установлен, оплата поинтами автоматически недоступна, а в меню кнопка показывается как «Недоступно».

### Рубли

Плагин **не принимает реальные платежи сам**. Рубли это внутренний баланс игрока в `data.yml`, который пополняет ваш донат-магазин (Tebex-аналог, Enot, Lava, собственный сайт и т.п.) после успешной оплаты командой выполнения в консоли:

```
msub rub add %player% %amount%
```

Игрок получит сообщение о пополнении, а потом сможет купить подписку в меню за рубли. Если рублей не хватает, ему покажут ссылку из `store-url` (клик открывает сайт).

Чтобы отключить одну из валют, поставьте `enabled: false` в `currencies.<валюта>`, либо оставьте у тарифа цену `-1`.

## Тарифы

```yaml
plans:
  month:                        # id тарифа (латиница, регистр не важен)
    name: "&f‹ &#00ACFFМесяц &f›"
    days: 30
    icon: GOLD_INGOT
    slot: 22                    # слот в главном меню (0–53)
    price:
      points: 450               # -1 или 0 — оплата поинтами недоступна
      rubles: 299               # -1 или 0 — оплата рублями недоступна
    lore:                       # дополнительные строки описания
      - "&fВыгоднее недели на &#00ACFF25%"
```

- Количество тарифов не ограничено, но в главном меню рекомендуется держать их в 3–5 слотах.
- Покупка продлевает уже активную подписку: срок прибавляется к текущему окончанию.
- Подписки, выданные вручную на произвольное число дней, помечаются тарифом «Особая» (`plan.custom` в `lang.yml`).

## Бонусы

Бонусы выдаются **всем подписчикам**. Они хранятся в `bonuses.yml`:

```yaml
bonuses:
  daily-reward:
    name: "&f‹ &#00ACFFЕжедневная награда &f›"
    icon: GOLDEN_APPLE
    type: DAILY
    cooldown-hours: 24.0
    lore:
      - "&fЗабирайте каждые &#00ACFF24 часа"
    commands:
      - "give %player% golden_apple 4"
    revert-commands: []
```

### Типы

| Тип | Когда выполняются `commands` | `revert-commands` |
|-----|------------------------------|-------------------|
| `ACTIVATE` | При каждой покупке или выдаче подписки (в том числе при продлении) | не используются |
| `DAILY` | Когда игрок сам забирает бонус (меню или `/premium claim`), не чаще кулдауна | не используются |
| `PASSIVE` | Когда подписка стартует с нуля (не при продлении) | При окончании, отмене или уменьшении срока до нуля |

### Команды бонусов

- Команды выполняются **от имени консоли**.
- Доступен плейсхолдер `%player%` (или `{player}`), ведущий `/` необязателен.
- Примеры:
  - `give %player% diamond 5`
  - `lp user %player% parent add premium` / откат `lp user %player% parent remove premium`
  - `eco give %player% 1000`

### Особенности

- Время последнего получения DAILY-бонуса хранится по каждому игроку и каждому бонусу, оно не сбрасывается продлением подписки.
- Если подписка закончилась, забрать бонус нельзя (сообщение «нужна активная подписка»).
- PASSIVE-откат выполняется и для оффлайн-игрока (по имени), поэтому команда отката должна поддерживать оффлайн-ники (LuckPerms поддерживает).
- В меню бонусов отображается до 28 бонусов.

## Меню (GUI)

### Главное меню `/premium`

- Центр: иконка **статуса** (тариф, остаток, дата окончания). Для активной подписки светится и пульсирует.
- Ниже: **тарифы** в слотах из конфига. Клик открывает выбор оплаты.
- Внизу: кнопки **«Бонусы подписки»** и **«Закрыть»**.

### Выбор оплаты

- Слева кнопка поинтов, справа кнопка рублей, в центре информация о тарифе.
- Показывает цену и баланс игрока (баланс подгружается асинхронно, пока идёт загрузка, показывается «...»).
- Если способ недоступен (валюта выключена, цена `-1`, нет PlayerPoints), кнопка заменяется на «Недоступно».
- После успешной покупки открывается главное меню с обновлённым статусом.

### Бонусы

- Список всех бонусов, DAILY-бонусы забираются кликом. Состояние (доступен / через сколько / нужна подписка) обновляется без перезапуска анимации.

### Анимации

- **Открытие:** слоты появляются волнами от центра к краям, звук поднимается по тону.
- **Idle:** по рамке бежит волна цветов из `gui.animation.palette`.
- Все предметы в меню защищены: их нельзя взять, перетащить или перенести шифтом.

## Плейсхолдеры и TAB

Идентификатор: `miragesub`. Требуется PlaceholderAPI.

| Плейсхолдер | Значение |
|-------------|----------|
| `%miragesub_active%` | `true` / `false` |
| `%miragesub_has%` | то же, что `active` |
| `%miragesub_status%` | текст из `placeholders.active` или `placeholders.inactive` |
| `%miragesub_timeleft%` | остаток в виде `2д 5ч 10м` (при отсутствии подписки значение `placeholders.none`) |
| `%miragesub_days_left%` | целых дней до конца (0 без подписки) |
| `%miragesub_hours_left%` | целых часов до конца |
| `%miragesub_expires%` | дата окончания по `settings.date-format` |
| `%miragesub_plan%` | название тарифа |
| `%miragesub_rubles%` | рублёвый баланс игрока |

Плейсхолдеры читают только данные в памяти, поэтому безопасны при вызове из асинхронных потоков (TAB).

### Пример для TAB (scoreboard)

```yaml
# plugins/TAB/config.yml
placeholder-refresh-intervals:
  default-refresh-interval: 500
  "%miragesub_status%": 1000
  "%miragesub_timeleft%": 1000
```

```yaml
# plugins/TAB/groups.yml или scoreboard-секция
lines:
  - "&fПодписка: %miragesub_status%"
  - "&fОсталось: &#00ACFF%miragesub_timeleft%"
```

### Условие для TAB (разный текст с подпиской и без)

```yaml
conditions:
  premium:
    conditions:
      - "%miragesub_active%=true"
    true: "&#00ACFF★ "
    false: ""
```

После этого `%condition:premium%` можно использовать, например, в `tabprefix`. Точный синтаксис зависит от версии TAB, сверяйтесь с его вики.

## Сообщения (lang.yml)

- Все сообщения игрокам и тексты меню находятся в `lang.yml`. Цвета: `&f`, `&#RRGGBB`.
- `{prefix}` подставляется автоматически из ключа `prefix`.
- Подстановки вида `{plan}`, `{left}`, `{expires}`, `{price}` и т.д. передаёт плагин. Не переименовывайте их внутри текстов.
- Списки (`lore`, `help.*`, `status.*`) выводятся построчно.
- Если ключ пропал, вместо текста будет выведено `[lang:ключ]`, а значение возьмётся из версии внутри jar при следующей загрузке, если оно там есть.

## Хранение данных

| Файл | Содержимое |
|------|------------|
| `config.yml` | Настройки, валюты, тарифы, плейсхолдеры |
| `lang.yml` | Сообщения и тексты меню |
| `bonuses.yml` | Бонусы (редактируется руками или `/msub bonus`) |
| `data.yml` | Профили игроков: срок подписки, тариф, рубли, время получения DAILY-бонусов |

Формат `data.yml`:

```yaml
profiles:
  <uuid>:
    name: Steve
    expires-at: 1767225600000   # unix-время окончания в миллисекундах, 0 — подписки нет
    plan: month
    rubles: 150
    claims:
      daily-reward: 1766000000000
```

Запись `data.yml` идёт через временный файл и атомарную замену, поэтому обрыв питания не оставит файл наполовину записанным. Не редактируйте `data.yml` руками на запущенном сервере: изменения будут перезаписаны.

Комментарии в `bonuses.yml` при сохранении командами `/msub bonus` пересоздаются заголовком файла; свои комментарии внутри секций лучше не оставлять.

```
├── payment/                      PaymentProvider, PlayerPointsProvider, RubleProvider, PaymentService
├── placeholder/SubscriptionExpansion   %miragesub_...%
├── service/                      SubscriptionService, PurchaseService, BonusService, результаты
├── storage/                      ProfileRepository (data.yml), BonusRegistry (bonuses.yml)
└── util/                         Text, Items, TimeFormat
```

Ответственность разделена: GUI и команды не знают, как устроена оплата или хранение, они обращаются к сервисам. Новый способ оплаты добавляется реализацией `PaymentProvider` и регистрацией в `PaymentService`.

## Многопоточность и производительность

- Чтение и запись файлов выполняются **только** в отдельном однопоточном IO-исполнителе (порядок записей сохраняется).
- Профили и бонусы хранятся в памяти: `ConcurrentHashMap`, неизменяемые карты, подменяемые целиком, `synchronized`-методы `Profile`.
- Покупка: списание средств выполняется вне главного потока (виртуальные потоки), а выдача подписки и команды бонусов выполняются на главном потоке (требование Bukkit для `dispatchCommand`).
- Защита от двойной покупки: игрок с покупкой «в полёте» не может запустить вторую.
- Если выдача подписки упала после списания, средства возвращаются.
- Проверка окончания подписок — лёгкая асинхронная задача; на главный поток переходит, только если есть что обработать.
- Единственное блокирующее ожидание: сохранение `data.yml` при остановке сервера (таймаут 5 секунд).

## Частые вопросы и проблемы

**Плейсхолдеры возвращают пустую строку.**
Данные ещё загружаются (первые секунды после старта), или у плагина нет профиля игрока. Без подписки `%miragesub_active%` вернёт `false`, а не пустоту.

**Оплата поинтами недоступна.**
Проверьте, что PlayerPoints установлен и включён, `currencies.points.enabled: true`, у тарифа `price.points > 0`. В консоли при старте будет предупреждение, если плагин не найден.

**Рубли не списываются / «Недостаточно рублей».**
Рубли — внутренний баланс. Пополните его `/msub rub add <ник> <сумма>`, проверьте `/msub rub balance <ник>`.

**`/msub give` пишет «игрок не найден».**
Игрок ни разу не заходил на сервер (его нет в кэше имён). Выдайте подписку, когда он онлайн.

**Бонус `PASSIVE` не сработал при продлении.**
Так и задумано: PASSIVE запускается только при старте подписки с нуля. Для выдачи при каждой покупке используйте `ACTIVATE`.

**Группа не снялась после окончания подписки.**
Проверьте `revert-commands` у PASSIVE-бонуса и что команда работает от консоли для оффлайн-игрока.

**Хочу без меню, только команды.**
`gui.enabled: false` и `/msub reload`.

**Хочу убрать анимацию.**
`gui.animation.enabled: false` (полностью) или `idle-step-ticks: 0` (только волна по рамке).

**Изменил `config.yml`, ничего не поменялось.**
Выполните `/msub reload`. Цены и тарифы применяются сразу, интервалы задач перезапускаются.

## Ограничения v0.1

- Рубли — внутренний баланс, прямой интеграции с платёжными системами нет (пополнение через консольную команду).
- Бонусы общие для всех подписчиков: разных бонусов для разных тарифов пока нет.
- В меню бонусов нет пагинации (до 28 бонусов).
- Хранилище — YAML-файл; для очень больших баз игроков позже стоит перейти на SQLite/MySQL (интерфейс хранилища изолирован в `storage/`).
- Проект не проходил автоматическую компиляцию и тесты в среде разработки ассистента: перед выкладкой на боевой сервер соберите его и проверьте покупку, окончание и бонусы на тестовом сервере.
